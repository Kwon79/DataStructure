큐(선입선출) //FIFO (First in First out) 뒤에서 들어와서 앞으로 나간다

큐 예시
1.줄 서기 // 들어온 순서대로 처리한다 

큐는 컴퓨터 시스템에서 굉장히 많이 사용되는 방법이다

Queue ADT
객체(Data)
-동일한 형태, 순서가 있는 데이터
연산
//생산,소멸
-CreateQueue(size) : size크기의 큐를 생성
-destoryQueue(Q): Q를 제거
-initQueue(Q):Q를 초기화
//상태
-emptyQueue(Q) : Q가 비어있으면 참을 반환
-fullQueue(Q):Q가 꽉 찾는지 확인
-enQueue(Q,I): Q에 아이템 I를 추가 //핵심연산
-deQueue(Q): Q에서 제일 앞에 있는 아이템을 삭제하고 반환 //핵심연산
-peekQueue(Q) :Q에서 제일 앞에 있는 아이템을 반환
//출력
-printQueue(Q): Q의 내용을 앞에서부터 출력

큐의 표현방법
1.배열
-rear,front --> enQueue할때 현재 rear가 가리키는 값에 값을 집어넣고 rear를 다음으로 가리키게한다
			--> deQueue할때 현재 front가 가리키는 값을 반환한고 front를 다음으로 가리키게 한다
문제점:일반 배열을 사용할 경우 메모리 손실이 일어남 (순차 큐의 문제점)
-해결 방안:제일 마지막의 rear를 제일 처음에 front를 가리키게 한다 (순차 큐의 문제해결->원형 큐)
(제일 처음 가리키는 front하고 rear가 같은 값을 가리킨다)
rear 계산법: rear=(rear+1)%10 , rear= front-1(full인상태)(rear는 front전까지만 저장받을수있게한다)

2.연결자료형
-(연결 큐) 데이터가 꽉차는게 마음에 들지 않는다 그럴 경우 사용
